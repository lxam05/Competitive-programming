Kattis Input with Scanner

Every example goes inside this:

import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        // code goes here
    }
}

Important: nextInt() leaves the newline behind. If you want to use nextLine() right after nextInt(), call sc.nextLine(); once first to clear it.

1. Groups ending with 0

Input:

3
Mozart
Beethoven
Bach
5
Hilbert
Godel
Poincare
Ramanujan
Pochhammmer
0

How to read it:

int n = sc.nextInt();
while (n != 0) {
    sc.nextLine();
    String result = "";
    int i = 0;
    while (i < n) {
        String name = sc.nextLine();
        result += name + " ";
        i++;
    }
    System.out.println(result.trim());
    n = sc.nextInt();
}

Output:

Mozart Beethoven Bach
Hilbert Godel Poincare Ramanujan Pochhammmer

2. Number of test cases first

Input:

3
5 7
10 20
1 1

How to read it:

int t = sc.nextInt();
while (t > 0) {
    int a = sc.nextInt();
    int b = sc.nextInt();
    System.out.println(a + b);
    t--;
}

Output:

12
30
2

5. N, then N numbers

Input:

5
3 8 1 9 4

How to read it:

int n = sc.nextInt();
int sum = 0;
int i = 0;
while (i < n) {
    sum += sc.nextInt();
    i++;
}
System.out.println(sum);

Output:

25

6. Different amount of numbers on each line

Input:

1 2 3
4 5
6 7 8 9

How to read it:

while (sc.hasNextLine()) {
    String line = sc.nextLine().trim();
    if (line.isEmpty()) continue;
    String[] parts = line.split("\\s+");
    int sum = 0;
    int i = 0;
    while (i < parts.length) {
        sum += Integer.parseInt(parts[i]);
        i++;
    }
    System.out.println(sum);
}

Output:

6
9
30

7. Grid of characters

Input:

3 4
#..#
.##.
#...

How to read it:

int rows = sc.nextInt();
int cols = sc.nextInt();
sc.nextLine();
int count = 0;
int r = 0;
while (r < rows) {
    String row = sc.nextLine();
    int c = 0;
    while (c < cols) {
        if (row.charAt(c) == '#') count++;
        c++;
    }
    r++;
}
System.out.println(count);

Output:

5

8. Number then full lines with spaces

Input:

2
John Smith
Mary Jane Watson

How to read it:

int n = sc.nextInt();
sc.nextLine();
while (n > 0) {
    String fullName = sc.nextLine();
    System.out.println("Hello, " + fullName);
    n--;
}

Output:

Hello, John Smith
Hello, Mary Jane Watson

9. Word sentinel (stop at END)

Input:

apple
banana
cherry
END

How to read it:

String word = sc.nextLine();
while (!word.equals("END")) {
    System.out.println(word.toUpperCase());
    word = sc.nextLine();
}

Output:

APPLE
BANANA
CHERRY

10. Two-number sentinel (stop at 0 0)

Input:

3 4
10 2
0 0

How to read it:

int a = sc.nextInt();
int b = sc.nextInt();
while (!(a == 0 && b == 0)) {
    System.out.println(a * b);
    a = sc.nextInt();
    b = sc.nextInt();
}

Output:

12
20

11. Mixed types on one line

Input:

3
Alice 20 3.5
Bob 19 2.8
Cara 22 3.9

How to read it:

int n = sc.nextInt();
while (n > 0) {
    String name = sc.next();
    int age = sc.nextInt();
    double gpa = sc.nextDouble();
    System.out.println(name + " is " + age + " with GPA " + gpa);
    n--;
}

Output:

Alice is 20 with GPA 3.5
Bob is 19 with GPA 2.8
Cara is 22 with GPA 3.9
